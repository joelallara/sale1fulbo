# Sale1fulbo

Esta aplicación es un proyecto inicial para organizar partidos de fútbol y reservar turnos en canchas que se asocien.

## Objetivo

Permitir que las personas puedan sumarse a partidos de fútbol cuando quieran a través de una plataforma web y móvil responsive.

## Estructura

- **backend/**: Servidor Express básico con endpoints para administrar partidos.
- **frontend/**: Aplicación web sencilla que consume la API.

## Cómo ejecutar

1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Iniciar el servidor:
   ```bash
   npm start
   ```
3. Abrir `frontend/index.html` en el navegador.

Este es solo un punto de partida que se puede expandir con autenticación, base de datos y una aplicación móvil (por ejemplo usando React Native).
